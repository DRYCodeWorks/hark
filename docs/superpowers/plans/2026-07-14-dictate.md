# dictate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hold ⌃⌥Space on the laptop, speak, and have the transcript appear in the Claude Code prompt inside a tmux pane on the server machine — with audio never leaving the author's hardware.

**Architecture:** A Hammerspoon client on the laptop captures mic audio via `ffmpeg` and POSTs a WAV to `dictated`, an HTTP service on the server. `dictated` transcribes via a resident `whisper-server`, sanitizes the text, and injects it **directly into the tmux pane's pty** using `load-buffer`/`paste-buffer -p` — bypassing the clipboard, ⌘V, the terminal emulator, and mosh entirely.

**Tech Stack:** Python 3.12 + FastAPI + uv (service, server) · Hammerspoon/Lua + ffmpeg (client, laptop) · whisper.cpp `whisper-server` (ASR, already installed) · launchd (both services) · Tailscale (transport)

## Global Constraints

- **server tailnet IP: `10.0.0.2`.** `dictated` binds to this address **only** — never `0.0.0.0`.
- **`whisper-server` binds to `127.0.0.1:8910`** (loopback only — it must not be tailnet-reachable).
- **`dictated` listens on port `8911`.**
- **Model:** `~/.local/share/whisper-cpp/ggml-large-v3-turbo.bin` (already on disk).
- **Audio format:** 16 kHz, mono, 16-bit PCM WAV. Whisper's native rate — never resample server-side.
- **Never send Enter / auto-submit.** the author reviews before sending.
- **Sanitization is mandatory** on every transcript before injection.
- **Repo:** `~/src/dictate`. Commit straight to `main` (DRYCodeWorks convention). **No `Co-authored-by` trailers.**
- **Python dependency management is `uv` only.** No `pip install` into a global env.

`src/tacet/sanitize.py`:

```python
"""Transcript sanitization.

Dictation never wants a literal newline. Collapsing them is what makes it
structurally impossible for a transcript to submit a prompt prematurely,
rather than relying on bracketed paste to save us.
"""

import re

# Covers C0 controls, DEL, and C1 (0x80-0x9f). C1 matters: U+009B (CSI) and
# U+009D (OSC) are single-byte equivalents of ESC[ and ESC], so stopping at
# 0x7f would let escape sequences through.
_CONTROL_CHARS = re.compile(r"[\x00-\x08\x0b\x0c\x0e-\x1f\x7f-\x9f]")
_WHITESPACE = re.compile(r"\s+")


def sanitize(raw: str) -> str:
    # Substitute rather than delete: a control char between two words must
    # separate them, not fuse them ("rm\x0c-rf" -> "rm -rf", never "rm-rf").
    spaced = _CONTROL_CHARS.sub(" ", raw)
    return _WHITESPACE.sub(" ", spaced).strip()
```

`src/tacet/tmux.py`:

```python
"""tmux target resolution and text injection.

Injection deliberately uses `load-buffer -` (transcript on stdin) rather than
`send-keys`, so the transcript is never interpolated into a command line and
cannot escape into shell or tmux command context. `paste-buffer -p` lets tmux
apply bracketed paste if the target application asked for it, so Claude Code
receives a genuine paste rather than synthetic keystrokes.
"""

import subprocess
from typing import Callable

Runner = Callable[..., str]

BUFFER_NAME = "dictate"


class NoTmuxClientError(Exception):
    """No tmux client is attached, so there is nowhere visible to inject."""


def _subprocess_run(argv: list[str], stdin: bytes | None = None) -> str:
    result = subprocess.run(
        argv, input=stdin, capture_output=True, check=True,
    )
    return result.stdout.decode("utf-8")


def resolve_target(run: Runner = _subprocess_run) -> str:
    """Return the session of the most recently active attached client.

    the author routinely has several clients attached at once, so 'most recent' is a
    real heuristic with a real failure mode - the caller surfaces the chosen
    target so a wrong guess is visible rather than silent.
    """
    out = run(["tmux", "list-clients", "-F", "#{client_activity} #{client_session}"])
    rows = [line.split(None, 1) for line in out.strip().splitlines() if line.strip()]
    if not rows:
        raise NoTmuxClientError("no tmux client attached")
    rows.sort(key=lambda r: int(r[0]), reverse=True)
    return rows[0][1]


def inject(text: str, target: str, run: Runner = _subprocess_run) -> None:
    if not text:
        return
    run(["tmux", "load-buffer", "-b", BUFFER_NAME, "-"], text.encode("utf-8"))
    run([
        "tmux", "paste-buffer", "-p", "-d", "-b", BUFFER_NAME, "-t", target,
    ])
```

`-d` deletes the buffer after pasting so transcripts don't accumulate in tmux's buffer stack.

"""HTTP client for whisper.cpp's whisper-server.

The server holds the model resident; a fresh `whisper-cli` per utterance would
reload 1.5 GB every time. Vocabulary biasing is applied at server startup via
--prompt (see launchd/), not per request.
"""

import httpx

from tacet import config


class WhisperUnavailableError(Exception):
    """whisper-server did not answer, or answered with an error."""


async def transcribe(wav: bytes, base_url: str = config.WHISPER_URL) -> str:
    files = {"file": ("audio.wav", wav, "audio/wav")}
    data = {"response_format": "json", "temperature": "0.0"}
    try:
        async with httpx.AsyncClient(timeout=config.TRANSCRIBE_TIMEOUT_S) as client:
            response = await client.post(
                f"{base_url}/inference", files=files, data=data
            )
            response.raise_for_status()
    except httpx.HTTPError as exc:
        raise WhisperUnavailableError(str(exc)) from exc
    return response.json()["text"]
```

"""The tacet service: audio in, text into a tmux pane.

Deliberately contains no business logic - sanitization, ASR, and injection each
live in their own module and are imported here by name so tests can fake them.
"""

import logging

from fastapi import FastAPI, HTTPException, Request

from tacet.sanitize import sanitize
from tacet.tmux import NoTmuxClientError, inject, resolve_target
from tacet.whisper import WhisperUnavailableError, transcribe

logger = logging.getLogger("tacet")

app = FastAPI(title="tacet")


@app.get("/health")
async def health() -> dict[str, str]:
    return {"status": "ok"}


@app.post("/dictate")
async def dictate(request: Request) -> dict:
    wav = await request.body()

    try:
        raw = await transcribe(wav)
    except WhisperUnavailableError as exc:
        logger.error("whisper-server unavailable: %s", exc)
        raise HTTPException(status_code=503, detail=str(exc)) from exc

    text = sanitize(raw)

    try:
        target = resolve_target()
    except NoTmuxClientError as exc:
        logger.warning("nowhere to inject: %s", exc)
        raise HTTPException(status_code=409, detail=str(exc)) from exc

    if not text:
        logger.info("empty transcript; injecting nothing")
        return {"text": "", "target": target, "injected": False}

    inject(text, target)
    logger.info("injected %d chars into session %s", len(text), target)
    return {"text": text, "target": target, "injected": True}
```

### Task 6: The laptop client

Runs on the **laptop**, not the server. Everything below happens on that machine.

**Files:**
- Create: `client/init.lua`

**Interfaces:**
- Consumes: `POST http://10.0.0.2:8911/dictate` with `content-type: audio/wav`

- [ ] **Step 1: Install prerequisites on the laptop**

```bash
brew install --cask hammerspoon
brew install ffmpeg
```

Grant Hammerspoon **two** permissions in System Settings → Privacy & Security:

- **Accessibility** — for the global hotkey.
- **Microphone** — because `ffmpeg` is spawned as Hammerspoon's child, macOS attributes the mic access to Hammerspoon, not ffmpeg. Miss this and recording silently produces a zero-byte WAV with no error.

The hotkey is **⌃⌥Space**, not ⌥⌘Space: the latter is macOS's built-in Finder search shortcut and the system wins that fight.

- [ ] **Step 2: Find the microphone's avfoundation index**

```bash
ffmpeg -f avfoundation -list_devices true -i "" 2>&1 | grep -A5 "audio devices"
```

Note the index of the mic you want (usually `:0` for the built-in). Substitute it below.

- [ ] **Step 3: Write the client**

`client/init.lua`:

```lua
-- dictate client: hold ⌃⌥Space, speak, release.
--
-- Hammerspoon holds the hotkey; it has no audio capture API (hs.audiodevice only
-- manages devices), so recording is an ffmpeg subprocess. That subprocess spawn
-- is the source of first-word clipping - measure before optimizing.

local SERVER = "http://10.0.0.2:8911/dictate"
local MIC = ":0"          -- from: ffmpeg -f avfoundation -list_devices true -i ""
local WAV = "/tmp/tacet.wav"
local FFMPEG = "/opt/homebrew/bin/ffmpeg"

local recorder = nil

local function beep()
  hs.sound.getByName("Funk"):play()
end

local function send()
  local f = io.open(WAV, "rb")
  if not f then beep() return end
  local audio = f:read("*all")
  f:close()

  hs.http.asyncPost(SERVER, audio, {["content-type"] = "audio/wav"},
    function(status, body)
      if status == 200 then
        local ok, parsed = pcall(hs.json.decode, body)
        if ok and parsed.injected == false then
          hs.alert.show("heard nothing")
        end
      elseif status == 409 then
        hs.alert.show("no tmux client attached")
        beep()
      else
        hs.alert.show("dictate failed: " .. tostring(status))
        beep()
      end
    end)
end

local function startRecording()
  if recorder then return end
  os.remove(WAV)
  hs.alert.show("●", 0.3)
  recorder = hs.task.new(FFMPEG, nil, {
    "-y", "-f", "avfoundation", "-i", MIC,
    "-ar", "16000", "-ac", "1", "-c:a", "pcm_s16le", WAV,
  })
  recorder:start()
end

local function stopRecording()
  if not recorder then return end
  recorder:terminate()   -- SIGTERM; ffmpeg finalizes the WAV header on exit
  recorder = nil
  hs.timer.doAfter(0.35, send)   -- let ffmpeg flush and close the file
end

-- ctrl+alt, NOT alt+cmd: ⌥⌘Space is macOS's Finder search shortcut.
hs.hotkey.bind({"ctrl", "alt"}, "space", startRecording, stopRecording)

hs.alert.show("dictate loaded")
```

`hs.hotkey.bind`'s third argument fires on key-down and the fourth on key-up — that is what makes this hold-to-talk.

### Task 7: Measure the three unknowns

The spec commits to measuring these rather than designing around them. Do that now, while the system is fresh, and record real numbers.

**Files:**
- Create: `README.md`

- [ ] **Step 1: Measure end-to-end latency**

Dictate a short sentence ten times. On the server: `grep injected /tmp/tacet.log`. Time from key-release to text appearing — use a stopwatch; sub-second precision is not needed to answer "is this pleasant to use".

Record the median in the README. If it exceeds ~2s, the next lever is Parakeet (measurably faster *and* more accurate than Whisper: 6.05% vs 7.44% WER), not micro-optimization.

- [ ] **Step 2: Measure first-word clipping**

Dictate `"one two three four five"` ten times, pressing the key and speaking **immediately** with no pause.

Count how many transcripts lose the "one". If it's more than ~1 in 10, the fix is a pre-warmed Swift recorder replacing the ffmpeg spawn — which is why the client's capture path was kept behind a clean boundary.

Also try it with a deliberate ~300 ms pause after pressing. If that fixes it, the workaround is free and the Swift rewrite can wait.

- [ ] **Step 3: Measure jargon accuracy**

Dictate this, verbatim:

> "Let's look at the ClickHouse MergeTree schema in the Graphite stack, then run the Alembic migration against Postgres and check the Tailscale route."

Count how many of the eight technical terms survive. Then edit `config.VOCAB_PROMPT` **and** the matching `--prompt` in the whisper-server plist, reload, and repeat.

This is the number that decides whether the deferred LLM cleanup pass is ever needed. Record it.

`README.md` must cover: what this is and why off-the-shelf apps can't do it (one paragraph, link the spec); the architecture diagram from the spec; install on the server; install on the laptop; **the three measured numbers**; and troubleshooting (`/tmp/tacet.log`, `/tmp/tacet-whisper.err`, the Hammerspoon console).

Do not write aspirational numbers. Write what you measured.
